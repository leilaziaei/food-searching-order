Food Searching & Ordering 🍔

A food search and ordering web application built with HTML5, CSS3, JavaScript (ES6+), and Tailwind CSS. The application allows users to explore recipes, search and filter meals, manage user accounts, and manage their shopping cart. Browser storage is used to preserve user information, cart contents, and search state.

Features

* Food Search: Search for recipes by name.
* Region-Based Filtering: Filter recipes by their region of origin.
* Ingredient-Based Filtering: Find recipes based on their ingredients.
* Category-Based Filtering: Browse recipes by category.
* User Registration: Create a new user account.
* User Login: Log in to an existing account.
* Shopping Cart: Add food items to the shopping cart.
* Remove Items: Remove food items from the shopping cart.
* Cart Management: Manage selected food items in the cart.
* Persistent Data Storage: Use localStorage to store user information and shopping cart data across page refreshes and browser sessions.
* Search State Persistence: Use sessionStorage to preserve search state across page refreshes within the same browser tab.
* Interactive User Interface: Explore and interact with food items through a dynamic user interface.

Technologies Used

* HTML5 – Structuring the application.
* CSS3 – Styling and layout.
* JavaScript (ES6+) – Implementing application logic and interactive features.
* Tailwind CSS – Styling the user interface.
* Web Storage API – Managing client-side data using localStorage and sessionStorage.

Getting Started

To run the project locally:

1. Clone the repository:

git clone https://github.com/leilaziaei/food-searching-order.git

2. Navigate to the project directory:

cd food-searching-order

3. Open index.html in your browser, or use the Live Server extension in Visual Studio Code.
